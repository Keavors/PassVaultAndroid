# PassVault для Android

Офлайн-хранилище паролей, парное к настольной версии
[PassVault](https://github.com/Keavors/PassVault). Формат файла `vault.pmv` общий;
синхронизация — перенос файла и слияние с разбором расхождений на любой из сторон.

Текущая версия: 3.1. История изменений по версиям — в [README_ANDROID.txt](README_ANDROID.txt).

## Возможности

Паритет с ПК: корзина, история паролей, архив снимков с ротацией «дед-отец-сын», слияние с
разбором расхождений, генератор, экспорт и импорт CSV/JSON (понимает Bitwarden и KeePass),
экспорт зашифрованной копии, открытие чужого файла, автоблокировка, очистка буфера обмена
через 30 секунд, растущая задержка после неверных паролей.

Что делает приложение для защиты данных:

- `FLAG_SECURE` — запрет скриншотов и предпросмотра в «недавних».
- Нет разрешения `INTERNET` — система не даст открыть сокет.
- `allowBackup="false"` — файл не уходит в облачный бэкап Google.
- Пароль в буфере обмена помечается как чувствительный (Android 13+).
- Запись с `fsync`, снимки тоже: внезапное выключение не оставит пустой файл.
- Незнакомые поля из более новой версии на ПК переживают перезапись телефоном.

## Форматы

Пишется только `PMVAULT2` (Argon2id: 3 прохода, 256 МиБ, 4 потока), считается чистой Java
(BouncyCastle). `PMVAULT1` (PBKDF2, файлы версий 1.x и 2.x) читается всегда; старый файл при
первом открытии сам переезжает на Argon2id, предварительно сняв копию в архив в прежнем формате.
Мастер-пароль не меняется.

Argon2id просит 256 МиБ на каждую попытку, поэтому в манифесте `largeHeap="true"`, а расшифровка
идёт в фоновом потоке с окошком «подожди».

## Где лежат данные

Внутреннее хранилище приложения (`files/`), другим приложениям недоступно:

| Файл | Что это |
|---|---|
| `vault.pmv` | хранилище |
| `vault.pmv.prev` | предыдущая версия для отката |
| `vault.pmv.bak` | копия от версии 1.x, читается при восстановлении |
| `vault_backups/` | архив снимков |
| `attempts.json` | счётчик неверных паролей |

Удаление приложения удалит и данные — держите копию на ПК.

## Синхронизация

- Телефон → ПК: «⋮» → Экспорт копии → файл на ПК → Файл → Слить с другим файлом…
- ПК → телефон: Файл → Сохранить копию как… → файл на телефон → «⋮» → Импорт и слияние.

Если файл зашифрован тем же паролем, что и текущее хранилище, пароль повторно не спрашивается.
Чтобы обе стороны стали одинаковыми: слейте на устройстве А, экспортируйте результат и слейте на Б.

## Сборка и тесты

Нужны JDK 17+ (подойдёт JBR из Android Studio) и Android SDK.

```bash
gradlew :app:testDebugUnitTest    # юнит-тесты ядра, без эмулятора
gradlew :app:assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

Релизная сборка подписывается отладочным ключом намеренно: приложение не публикуется,
а неподписанный APK не установить.

Ядро (`Core.kt`) не обращается к `android.*`, поэтому криптография, модель, слияние, запись
на диск, ротация снимков и задержка попыток проверяются обычными JVM-тестами.

## Совместимость с ПК

Проверяется на настоящих файлах в обе стороны:

- ПК → Android: `python tools\make_android_fixture.py` в проекте ПК кладёт в
  `app/src/test/resources` два эталона (`pc_vault_argon2.pmv`, `pc_vault.pmv`); их читает
  `PcCompatibilityTest`.
- Android → ПК: тест `PcCompatibilityTest.writesFileForPcToRead` пишет
  `app/build/interop/android_vault.pmv`, который читают тесты ПК.
